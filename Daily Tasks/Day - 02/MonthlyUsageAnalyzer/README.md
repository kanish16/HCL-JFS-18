# Monthly Usage Analyser

A Java console application that analyses monthly electricity usage.

## Concepts Covered

- int arrays
- 2-D arrays
- static final constants
- loops
- conditional statements
- ternary operator
- char
- type casting
- integer overflow
- long data type
- total, average, maximum and minimum
- electricity slab calculation

## Features

- Analyse 12 months of usage
- Calculate total usage
- Calculate average usage
- Find maximum usage
- Find minimum usage
- Assign usage grade
- Calculate estimated electricity bill
- Analyse usage for 3 houses
